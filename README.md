# Concepto central

Ashline es un juego de supervivencia en primera persona ambientado en un tren que avanza sin destino por un mundo tomado por zombies. El jugador es el único tripulante, y su trabajo no es llegar a ningún lado: es mantener el tren andando el mayor tiempo posible, gestionando vagones intercambiables, recursos limitados y amenazas que escalan con el tiempo. El tono es sombrío, con el humor negro apareciendo solo como un toque ocasional, nunca como el foco.

El proyecto nace como práctica paralela de desarrollo en Godot y modelado en Blender, y se piensa en dos etapas: una v1 acotada y cerrada (todo ocurre dentro del tren), y una v2 que abre el mundo a la exploración una vez que los sistemas centrales ya estén sólidos.
